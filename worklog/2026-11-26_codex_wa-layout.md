- 京香を参考候補から外す。縦組み、画像配置、写真の少ない区画を業種横断で比較する。

## 探し方

- [SANKOU! 縦書き・縦組み](https://sankoudesign.com/category/verticaltext/)を主に、[和風](https://sankoudesign.com/category/japanesestyle/)・[下層ページ](https://sankoudesign.com/category/nice-lowerlayer/)も照合。
- [デザインのこと 和風](https://designnokoto.com/tone/japanese-style)では写真・文章主体まで拡張し、[該当掲載](https://designnokoto.com/sp/13354)から「いつかのこと」へ。[S5-Style 和風](https://www.s5-style.com/all/style/japanese-style/)から並木秀俊、春風亭与いち、五箇サウナへ。[MUUUUU 和風](https://muuuuu.org/category/taglist/japan)とSANKOU!の和風から宝善亭・千夜賀風を比較。
- 選定は①縦組みが写真や余白の位置を決めているか ②スマホで何を縦のまま残すか ③写真が少ない区画にも転用できるか。背景色や業種は選定条件にしない。京香は候補から外した。

## Chrome実画面の比較

| 実サイト | 観察と使いどころ |
| --- | --- |
| [いつかのこと](https://itukanokoto.com/) | PC1100とSP390。冒頭は生成りの大きな余白に縦題字。PCの本文は左右交互の写真脇に短い縦文が来る。SPでは題字は縦のまま、写真つき本文は横組み。店の紹介と刺盛りへのつなぎ方の本命。 |
| [馬路村森林組合](https://umaji-shinrin.com/) | PC1100とSP390。写真の片側に縦長の短い言葉を2列置き、冒頭以降は横書きの説明と大小の写真。スマホでも主写真と縦の言葉が同じ画面で成立。外観の幟や看板を文字で隠さない構図の参考。 |
| [千夜賀風 コンセプト](https://senya-gafu.com/concept/) | SP390。写真の次に白い独立した区画を置き、中央に明朝の短い縦組み、その下に横書き本文。外観の次に店の紹介を置くときの参考。PCは読込タイムアウト。 |
| [並木秀俊](https://hidetoshinamiki.com/) | PC1100とSP390。大きな作品画像の中央に縦の署名を通す。1枚と短い文字の組み合わせ。下へ送る動きは取得画面から判断できなかった。 |
| [春風亭与いち](https://yoichi-shumputei.com/) | PC1100とSP390。青い面に人物の切り抜き1点と筆文字。PCは左端の縦長ナビ領域、SPは上部にメニュー、筆文字と写真の重なりに組み替える。筆文字を面の重心にする参考。 |
| [J-CAT](https://j-cat.co.jp/) | 前回ChromeでPC・SP確認。白い画面に離して置いた短い縦文とロゴ。写真なしの区画で、短いコピーと余白だけでも成立する参考。 |
| [宝善亭 About](https://www.houzentei.jp/about) | 前回ChromeでPC・SP確認。PCは小さな縦のラベル、横長写真、本文をずらして配置。SPは写真→縦ラベルと見出し→本文の順に読める構成。 |

- 五箇サウナと五◯祭はChromeでページ名を確認したが画像取得がタイムアウトしたため、実画面比較から除外。
- あさまるではヘッダー・フッターなどロゴタイプを置く面を白で固定する。素材のファイル形式・透明度は今回確認していない。
- 次案では外観写真の隣に余白と短い縦組みを置き、スマホでは写真の直後に縦組みを独立させる。刺盛りは本文側で大きく1枚使い、定番の品、営業時間・アクセス・応募は横組みで読めるようにする。サイト実装とVercel更新は今回の対象外。
